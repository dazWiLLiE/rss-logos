# rss-logos

Små avatarbilder (PNG, 128–256 px) för mina RSS-notiser. Discords webhooks hämtar avataren från en publik adress, så bilderna ligger här.

Adress per bild: `https://raw.githubusercontent.com/dazWiLLiE/rss-logos/main/<namn>.png` (se `logos.json`).

Logotyperna tillhör respektive ägare och används här bara som liten avatar för mina egna notiser. Inget annat i repot.
